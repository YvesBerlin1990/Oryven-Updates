# Oryven 1.0.88

- Links und Webseitenaktionen, die einen neuen Tab anfordern, öffnen wieder einen Tab im vorhandenen Browserfenster. Das gilt auch für Strg- und Mittelklick, JavaScript-Aufrufe und Formulare mit neuem Ziel. Ausdrücklich angeforderte Pop-up-Dialoge bleiben eigene Fenster.
- Beim Schließen eines von einer Webseite geöffneten Tabs bleibt das übrige Browserfenster geöffnet. Profil, Privatmodus, Formularübertragungen und Rückmeldungen an die Ursprungsseite bleiben erhalten.
- Orvonkey zeigt bereits installierte Scripts sofort aus der lokalen Ablage. Verbundene Repositorys werden anschließend im Hintergrund auf Aktualisierungen geprüft. Eine langsame Verbindung oder fehlgeschlagene Prüfung blockiert die lokale Sammlung nicht und entfernt keine installierten Scripts.
- Bewusst deaktivierte Scripts bleiben deaktiviert. Scriptwerte, Profile, Lesezeichen, Passwörter und Einstellungen bleiben erhalten.
- Wird ein verbundenes Script nachweislich auf GitHub gelöscht, entfernt Orvonkey auch seine lokale Installation. Verbindungsfehler, fehlende Leserechte oder unvollständige GitHub-Antworten lösen keine lokale Löschung aus.
- Die Auslieferung erfolgt über den bestehenden internen Updateweg ohne erneute Einrichtung oder Profilumzug.

Öffne in Oryven **Einstellungen → Über Oryven → Nach Updates suchen**, lade das Update herunter und wähle **Installieren und neu starten** oder die Installation beim Beenden. Voraussetzung ist eine bereits auf das native EXE-System umgestellte Installation ab Oryven 1.0.85.
