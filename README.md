# Oryven Updates

Offizieller Downloadkanal für Oryven-Installationen und automatische Updates.

Dieses Repository enthält ausschließlich fertige Binärpakete. Der Oryven-Quellcode wird hier nicht veröffentlicht.

Die aktuelle Installation findest du unter [Releases](https://github.com/YvesBerlin1990/Oryven-Updates/releases/latest). Automatische Updates verwenden den Kanal `private` und die Datei `releases.private.json`; der Kanalname bezeichnet keine GitHub-Zugriffsbeschränkung.

Für künftige Veröffentlichungen ist zusätzlich `source-<Version>.json` als Herkunftsnachweis vorgesehen: Quellcode-Commit, Inhaltsfingerabdruck und Paketprüfsummen. Die Einführung erfolgt mit den Korrekturen im privaten Quellcode-Repository; ältere Releases enthalten diese Datei noch nicht. Die Prüfsummen ergänzen eine Codesignatur, ersetzen sie aber nicht.

Veröffentlichte Versionen dürfen nicht durch neue Dateien gleichen Namens ersetzt werden. Korrekturen erhalten eine neue Versionsnummer. Entwürfe derselben oder einer älteren Version dürfen die Wahl der nächsten Version nicht beeinflussen.
